# dragon

Recolored for the Dragonite-inspired orange/cream dragon redesign (creature moved away from
purple to warm orange body / cream belly, so the hub background follows):

- Master raw-0: warm amber/golden-hour **sky sanctum** — sunlit sandstone pillars/archways with
  amber gem accents, floating cliffside dais, golden clouds, distant sunlit peaks, empty
  circular stand ring. No volcano/lava, no purple crystals/arcane ruins.
- motion.txt = **sparks_up** (golden rising motes, geometry locked) — swapped from `arcane_up`
  because that mode's particle/ring overlay is hardcoded purple/magenta in
  `scripts/home_bg_pipeline.py`, which would clash with the new warm palette.
- The purple aura/projectile/impact battle FX (`assets/battle/fx/dragon/**`) are unchanged and
  intentionally stay purple as the element's "dragon energy" accent color — unrelated to this
  background/creature recolor.
